# PinkCut Studio - Booking Jasa Editing (PHP + MySQL)

## Cara menjalankan (XAMPP)
1. Nyalakan Apache dan MySQL di XAMPP.
2. Salin folder `pinkcut-booking` ke `C:\xampp\htdocs\`.
3. Buka http://localhost/phpmyadmin, klik Import, pilih `database.sql`, lalu Go.
   Database baru bernama `pinkcut_booking` (database lama tidak terganggu).
4. Halaman user : http://localhost/pinkcut-booking/
5. Halaman admin: http://localhost/pinkcut-booking/admin/login.php
   Email admin@booking.com | Password: password (segera ganti)

## Pengaturan (includes/functions.php)
Nomor WA, jam slot, metode pembayaran, dan user/password MySQL.
